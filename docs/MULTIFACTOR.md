## Вердикт: НЕ ПРОШЛА

Три условия из четырёх выполнены; нижняя граница CI95 ниже нуля. Результат
совместим с нулём. Holdout для этой модели не используется — так записано
в спецификации.

**Почему «почти» не считается.** Это одиннадцатый замер. Даже на чистом
шуме хотя бы один из одиннадцати покажет t >= 1.5 с вероятностью заметно
выше половины. Сильнейший результат серии — ровно то место, где
самообман дешевле всего. Подкрутка λ или состава признаков ради сдвига
интервала запрещена спецификацией.

Два крупнейших веса — оба про волатильность, с одним знаком. Это
узнаваемая аномалия низкой волатильности (Ang–Hodrick–Xing–Zhang 2006;
Frazzini–Pedersen 2014, «Betting Against Beta»), одна из самых устойчивых
в литературе на разных классах активов. Модель её не знала — нашла сама.
