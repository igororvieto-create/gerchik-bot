# Замер VII: режим рынка как фильтр направления — результат

Гипотеза, спецификация и планка записаны в `docs/PREREGISTRATION.md`
2026-09-16, в момент, когда гипотеза была увидена. Инструмент вердикта
(`tools/verdict_vii.py`) закоммичен ДО взгляда (`8f1b3fa`); взгляд сделан
один раз 2026-09-28.

## Откуда взялась гипотеза

Срез «направление × режим рынка» на 211 исходах до 16.09 показывал:
шорты в падающем рынке +0.732R, лонги −0.755R. Вывод «торгуй по дрейфу
рынка» был увиден в тех же данных, где родился, поэтому проверялся только
на НОВЫХ: сигналах, созданных после 2026-09-16 06:22 UTC.

## Результат

Дрейф — изменение BTC за 48 ч ДО сигнала, по барам, закрытым к моменту
сигнала. Боковик (|дрейф| < 1%) исключён: 132 исхода.

## Вердикт: НЕ ПРОШЛА

| Условие | Факт | |
|---|---|---|
| исходов >= 120, в группе >= 40 | 270: 68 / 202 | ✓ |
| `ev_r` группы «по дрейфу» > 0 | −0.221 | ✗ |
| нижняя граница CI95 > 0 | −0.692 | ✗ |
| разница положительна и значима | −0.109 | ✗ |

**Знак обратный гипотезе**, как и в замере потока: торговля по дрейфу
оказалась хуже торговли против него. Разница незначима, поэтому
утверждать обратный эффект нельзя — но и прямого нет.

Как записано заранее: фильтр по режиму рынка не вводится, наблюдавшаяся
асимметрия — свойство выборки, а не стратегии, и к ней больше не
возвращаемся.

## Попутное наблюдение: сигналы сильно скучены

Поправка на перекрытие меток — ×2.1 и ×2.5: в среднем каждый сигнал делит
окно оценки ещё с одним-полутора сигналами по тому же символу. 270
исходов весят как ~113 независимых. Это важно для любой будущей оценки
«на глаз» по дашборду: число решённых сигналов вдвое-втрое завышает
реальный объём информации.
