# Реестр находок ревью 2026-09-03

Ревью по ролям (B — деньги, C — данные) плюс собственная проверка ролей A и
D. Каждая находка перепроверена чтением кода: отчёт агента — гипотеза.

Файл существует ради одного: находка без записи теряется. Строка «сделано»
ставится ТОЛЬКО когда есть тест и мутация, которая его роняет.

## Осталось открытым — намеренно

### 13. Отказ сокращения оставляет риск выше 3%
Обе ветки отказа оставляют позицию жить, вход возвращает успех. Это
осознанный компромисс автора (закрывать позицию силой при отказе биржи
опаснее, чем нести повышенный риск), но инвариант CLAUDE.md он нарушает.
Решение требует выбора владельца: закрывать силой или мириться. Пока
предупреждение идёт только в лог — стоит вывести на дашборд.

### 14. Отказ ордера с «обычным» кодом снимает слот, не спросив биржу
PLAUSIBLE. Соседняя ветка (потерянный ответ) устроена правильно и читает
биржу; эта — нет. Доказать без живого API нельзя: нужен реальный код
ответа Bybit, при котором ордер принят и отвечено ошибкой. Асимметрия
двух соседних веток — факт, читаемый в коде, и её стоит устранить в
пользу более осторожной ветки.
